# Using Agent Skills — compact reference

Skills are selected by relevance. Prefer the most specific skill for the current task and avoid activating unrelated skills.

## Selection
- vague requirements → `interview-me` or `idea-refine`
- new/significant feature → `spec-driven-development` → `planning-and-task-breakdown`
- implementation → `incremental-implementation` plus only the needed domain skill
- tests → `test-driven-development`
- failure → `debugging-and-error-recovery`
- review → `code-review-and-quality`
- security/performance/browser → the corresponding specialized skill
- deploy/release → `shipping-and-launch`

Do not use this skill as a mandatory preamble to every request.
